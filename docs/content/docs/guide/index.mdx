# Getting Started

Three steps to your first working PraxisJS app. After these, move straight into [Core Concepts](/docs/essentials) to understand the reactive model in depth.

<Steps>
  <Step>
    ### Understand the model

    Read [Introduction](/docs/guide/introduction) to learn what PraxisJS is and how signals eliminate the need for a virtual DOM. It takes five minutes and answers 90% of future "why does this work this way?" questions.
  </Step>
  <Step>
    ### Create your project

    Run `npm create praxisjs@latest` to scaffold a ready-to-go project, or follow [Quick Start](/docs/guide/getting-started) for manual setup. You'll have a running counter component in under two minutes.
  </Step>
  <Step>
    ### Learn the core

    Work through [Core Concepts](/docs/essentials) — components, reactivity, JSX, lifecycle hooks, and async data. Read them in order the first time; each builds on the previous.
  </Step>
</Steps>

## The three rules

All of PraxisJS follows from just three rules. Internalize these and everything else clicks into place.
