## Required setup for every project

Every PraxisJS project needs these two files configured correctly:

<Steps>
  <Step>
    ### Install and configure the Vite plugin

    <PackageInstall pkg="@praxisjs/vite-plugin" dev />

    ```ts
    // vite.config.ts
    import { defineConfig } from 'vite'
    import { praxisjs } from '@praxisjs/vite-plugin'

    export default defineConfig({
      plugins: [praxisjs({ hmr: true })],
    })
    ```
  </Step>
  <Step>
    ### Configure TypeScript

    ```json
    // tsconfig.json
    {
      "compilerOptions": {
        "target": "ES2022",
        "module": "ESNext",
        "moduleResolution": "bundler",
        "jsx": "react-jsx",
        "jsxImportSource": "@praxisjs/jsx",
        "useDefineForClassFields": false,
        "strict": true,
        "noEmit": true
      }
    }
    ```

    <Callout type="warn" title="`useDefineForClassFields: false` is required">
      With `true`, TypeScript compiles class fields via `Object.defineProperty`, which runs after decorator initializers and overwrites the signal wiring they set up. Set it to `false` so field assignments are treated as constructor assignments and decorators work correctly.
    </Callout>
  </Step>
  <Step>
    ### Mount your app

    ```ts
    // src/main.ts
    import { render } from '@praxisjs/runtime'
    import { App } from './App'

    render(() => <App />, document.getElementById('app')!)
    ```
  </Step>
</Steps>

## Start from scratch

Skip the manual setup entirely:

```sh
npm create praxisjs@latest
```

Choose from Minimal, With Router, Full, or Blog templates — all pre-configured with TypeScript, Vite, JSX, and HMR.

Already have a project? See the [praxisjs CLI](/docs/tooling/cli) for `doctor` (diagnostics) and `upgrade` (dependency updates).
