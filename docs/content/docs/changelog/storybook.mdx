# @praxisjs/storybook

## 0.1.1

## 0.1.0

Initial release — Storybook framework adapter for PraxisJS. Mounts components via `@praxisjs/runtime`, integrates `@praxisjs/vite-plugin` automatically, and exports `Meta`, `StoryObj`, and `StorybookConfig` types.
