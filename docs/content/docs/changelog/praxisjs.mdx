# praxisjs

## 0.1.0

Initial release. Provides `praxisjs add` — installs an AI integration (Claude Code or Codex skill) into an existing project. This is the same `add` command previously shipped in `create-praxisjs`, moved here so it can grow into a general maintenance CLI for existing PraxisJS projects.
