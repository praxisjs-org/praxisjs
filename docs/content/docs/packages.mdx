# Packages

All public packages published to npm. Versions follow [semantic versioning](https://semver.org) — breaking changes only happen in major bumps.

## Foundation

Core packages that every PraxisJS project depends on.

| Package | Version | Description |
| ------- | ------- | ----------- |
| `@praxisjs/core` | `1.6.0` | Reactivity engine — `signal`, `computed`, `effect`, `batch`, `peek`, `untrack`, `resource` |
| `@praxisjs/decorators` | `1.0.2` | Class component decorators — `@State`, `@Prop`, `@Watch`, `@Emit`, `@Compose`, `@Resource` |
| `@praxisjs/runtime` | `0.2.18` | DOM renderer — mounts components, manages scopes, handles reactive children |
| `@praxisjs/jsx` | `0.4.6` | JSX runtime (`jsx-runtime`, `jsx-dev-runtime`) |
| `@praxisjs/shared` | `0.2.0` | Shared types and internal utilities (not installed directly) |

```bash
npm install @praxisjs/core @praxisjs/decorators @praxisjs/runtime @praxisjs/jsx
```

## Packages

First-party plugins — install only what your project needs.

| Package | Version | Description |
| ------- | ------- | ----------- |
| `@praxisjs/content` | `0.1.0` | Markdown content collections with `@Collection`, `@PagedCollection`, frontmatter validation, and Vite plugin |
| `@praxisjs/router` | `1.1.0` | Client-side router with `@Router` and `@Route` decorators |
| `@praxisjs/store` | `1.2.0` | Class-based singleton state with `@Storable` and `@Store` |
| `@praxisjs/di` | `1.3.0` | Decorator-based dependency injection with scoped containers |
| `@praxisjs/motion` | `1.1.11` | `@Tween` and `@Spring` animated field decorators |
| `@praxisjs/fsm` | `2.0.0` | `@StateMachine` and `@Transition` finite state machines |
| `@praxisjs/concurrent` | `1.2.9` | `@Task`, `@Queue`, `@Pool` async concurrency control |

```bash
npm install @praxisjs/router
npm install @praxisjs/store
npm install @praxisjs/di
npm install @praxisjs/motion
npm install @praxisjs/fsm
npm install @praxisjs/concurrent
```
